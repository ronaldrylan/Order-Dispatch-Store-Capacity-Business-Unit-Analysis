How these numbers are calculated

  • Plan basis. "Initial plan" counts only Initial Planned rows. "+ Next schedules" also counts orders available for the next schedules, which is how the Excel macro works.
  • "Orders" are units (EWM OBDO item quantity). OBDs are counted as delivery documents.
  • Dispatched = Dispatch Status contains "Dispatched"; units are Packed QTY, or planned QTY when nothing is packed. Affected = planned rows not dispatched.
  • Store capacity = Column Q, counted once per ship-to (highest value among Initial Planned rows). Utilization = dispatched units / store capacity.
  • Over-cap rows (PGI delayed due to overcapacity) are never part of the plan. They appear in the available orders table as their own source.
  • Upload data. Use the Upload data button, or drop a file anywhere on the page. It reads the sheet named Data (or the first sheet with the same columns) from an .xlsx, .xlsm or .csv file. Nothing leaves your browser.
  • The business unit table counts planned units of dispatched and affected rows only, as in the workbook.
  • Whse Proc. Type here is the real warehouse process type (2012, 2010 …). The Excel dashboard shows Pending QTY in that column.
